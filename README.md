# 鶴屋 公式サイト

東大阪・布施の自家焙煎コーヒー豆店「鶴屋」の静的Webサイトです。

- 本番URL: https://www.tsuruya-cafe.com/
- オンラインストア: https://tsuruyacafe.thebase.in/
- ホスティング: GitHub Pages
- Google Analytics: 既存GA4データストリーム（測定ID `G-MWPNN29GQ5`）

## 互換URL

- `/shopinfo/` — 正規URL`/shopinfo`へ転送
- `/shopinfo/”` — 大阪商店街サイトの誤記されたリンクを受け、正規URL`/shopinfo`へ転送

## 公開前チェック

- 店舗の営業時間・住所・電話番号を確認する
- GitHub PagesのCustom domainに`www.tsuruya-cafe.com`を設定する
- DNS切り替え後にHTTPSを有効化する
- Search Consoleへ`sitemap.xml`を送信する
